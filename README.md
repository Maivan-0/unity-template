A modular collection of core mechanics and reusable systems for Unity game development, serving as a foundation for player, enemy, trap, and UI architecture.

Key Features & Included Systems:
- Player Mechanics: Core movement, jump physics, melee & bow combat, Camera Manager with screen shake, health system, and Player Stats.
- Enemy AI & Behaviors: Base class setup, patrol routines, melee attacks, and ranged combat logic.
- Traps & Environment: Moving platforms, mechanical hazards (spikes, spikes/shurikens), and directional arrow shooters.
- UI & Systems: Interactive inventory (drag-and-drop, crafting via Scriptable Objects), pause menu, and audio/video/controls settings using Input Manager.

Tech Stack: Unity, C#, Scriptable Objects
